# MenuDate

MenuDate は、Google カレンダーなどの予定をメニューバーから確認する macOS アプリです。予定は macOS のカレンダーから EventKit で取得し、「インターネットアカウント」に追加したアカウントのカレンダーをまとめて表示します。メニューバーのボタンをクリックすると、ポップオーバーを表示します。表示モードは、月表示とコンパクト表示の 2 つです。

## 必要環境

- macOS 15 以降
- Swift 6.2 以降のツールチェーン。Xcode 26 以降に含まれます

## 予定を表示する準備

MenuDate 自体にはサインインがありません。macOS が同期したカレンダーを読むので、Google 側の設定は要りません。

### Google アカウントを追加する

1. macOS の「システム設定」を開き、「インターネットアカウント」を選びます
2. 「アカウントを追加」を押し、「Google」を選んで、画面の案内に従ってサインインします。複数のアカウントを追加できます
3. 追加したアカウントの「カレンダー」をオンにします

iCloud やその他の CalDAV のアカウントも、同じ手順で追加すると表示されます。アカウントの追加と削除は、MenuDate ではなく「インターネットアカウント」で行います。MenuDate の設定画面にも「「インターネットアカウント」を開く」ボタンがあります。

### カレンダーへのアクセスを許可する

1. MenuDate を起動し、メニューバーのカレンダーのアイコンをクリックします。アイコンを押したディスプレイのメニューバーの下に、パネルが開きます。パネルの外をクリックするか、Esc キーを押すか、アイコンをもう一度押すと閉じます
2. 「カレンダーへのアクセスを許可」を押します
3. macOS のダイアログで、フルアクセスを許可します

許可を求めるのは、このボタンを押したときだけです。起動時には求めません。許可を拒否したときは、ポップオーバーに「システム設定を開く」が出ます。「プライバシーとセキュリティ」の「カレンダー」で、MenuDate にフルアクセスを許可します。

`scripts/bundle.sh` が作る `MenuDate.app` は ad-hoc 署名です。ビルドし直すと macOS が別のアプリとして扱い、カレンダーへのアクセスの許可をもう一度求めることがあります。その場合は、同じ手順で許可します。

## 表示モード

- 月表示: 予定をマス目の中に並べた、大きな 1 枚のカレンダーです。既定のモードです。ポップオーバーは、開いた画面の大きさに合わせて大きく開きます。日を押すと、マス目の右の欄に、その日の 1 日のスケジュールが時刻順に出ます。予定を押すと、さらに右の詳細の列に詳細が開きます（スケジュールは出したままで、開いた予定は強調されます）。予定を選んでいないときは、詳細の列に空の状態を出します。画面が狭いときは詳細の列を出さず、スケジュールの欄に詳細を開きます。入りきらない日の「他 N 件」を押すと、その日が選ばれ、全件がスケジュールの欄に出ます
- コンパクト表示: 幅の狭い月のカレンダーと、日ごとの予定一覧です。予定一覧は選択日から始まり、スクロールすると日が進みます

モードは、ポップオーバーの上の切り替えか、キーボードの ⌘1（月表示）と ⌘2（コンパクト表示）で切り替えます。選んだモードは、次に開いたときも使われます。

## アカウントとカレンダーの操作

- 設定のカレンダータブで、アカウントごとに、表示するカレンダーを切り替えます
- 複数のアカウントが同じ予定を持つときは、アカウントの並び順で先のアカウントの予定を 1 件だけ表示します。アカウントは名前の順です。祝日カレンダーや、複数のアカウントに招待された会議が、この場合に当たります
- 予定に Google Meet、Zoom、Teams、Webex の URL があれば、予定の行から開けます
- 予定の取得は、macOS がカレンダーを同期した結果に依存します。予定が出ないときは、「システム設定」の「インターネットアカウント」で、アカウントのカレンダーがオンになっているかを確かめます

## ビルドと起動

```sh
swift build                        # ビルド
swift test                         # テスト
scripts/bundle.sh                  # MenuDate.app を組み立てます
open -g -j <MenuDate.app のパス>    # 前面に出さずに起動します
```

画面の見た目を PNG で確認するときは、次のコマンドを実行します。画面にウィンドウを表示せず、フォーカスも奪いません。

```sh
swift run menudate-snapshots .playwright/snapshots
```
